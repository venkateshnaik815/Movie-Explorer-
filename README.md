# Movie-Explorer-

A modern, responsive Movie & Sports web application built with React, Vite, and TMDB API.

## Features

- **Discover Movies**: Explore trending movies, top rated, popular, and upcoming films.
- **Telugu & English Categories**: Dedicated sections for Tollywood and Hollywood cinema.
- **Movie Details**: Full synopses, cast info, release dates, ratings, and YouTube trailer embeds.
- **Live Sports Hub**: Cricket match scores, highlights, and schedules.
- **Personal Favorites**: Save movies to your local watchlist.
- **Search & Filters**: Instant debounced search and genre-based filtering.
- **Responsive & Modern UI**: Netflix-inspired dark aesthetic with slick animations.

## Tech Stack

- **React 19**
- **Vite**
- **React Router v7**
- **React Icons**
- **TMDB API**

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/venkateshnaik815/Movie-Explorer-.git

# Navigate to project directory
cd Movie-Explorer-

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production

```bash
npm run build
```
